# TASK ESPECIFIC PROMPTING
Según el tipo de tara se tine una **técnica dominante**

-  ¿Qué tipo de trabajo es?: Resumir, extraer, crear, decidir, revisar.
- En qué fomrato necesito el resultado

## TIPOS DE TAREA
1. Comprimir - Tareas de comprensión
    - Resumir: Audiencia, longitud, propósito
    - Extrar: Esquema, etiquetas XML y ejemplos
2. Transformar
    - Traducir: Define primero un glosario
    - Reformatear: Un ejemplo de antes y después
3. Crear
    - Redactar: Rol, Tono y ejemplos
    - Idear: Cantidad y diversidad
4. Juzgar
    - Analizar: Razonamiento y evidencias
    - Revisar: Criterios explícitos


> El **verbo** define lo que hara Claude, por ello si quieres que Claude **actue** usar un **verbo de acción direct**
